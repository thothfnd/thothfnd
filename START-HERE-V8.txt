THOTHFND — V8 IMMERSIVE PROFILE

1. Upload/replace ALL files from this package in your thothfnd/thothfnd repository.
2. The important workflow is:
   .github/workflows/refresh-profile.yml
3. Edit data/profile.json later to add Telegram / Channel / Website links.
4. Go to GitHub -> Actions -> Refresh immersive profile -> Run workflow.
5. The workflow automatically removes known V1-V7 legacy files, stale SVGs and old scripts, regenerates the V8 assets, then commits the cleanup.
6. THOTH Browser and RelayX repository links activate automatically when matching public repositories exist on the same GitHub account. Explicit URLs in data/profile.json override auto-detection.

START-HERE-V8.txt is itself removed automatically by the first V8 refresh if it was uploaded to the repo.
