# THOTH /FND — V3.0.4 Apple-Typewriter Motion Patch

Scope is deliberately limited to the Hero.

## Fixes

- Main `systems / built different.` animation now uses an SVG stroke-writing pipeline modeled on the selected Apple Hello reference:
  - vector glyph outlines
  - `pathLength`-style 0→1 stroke drawing
  - round caps/joins
  - ease-in-out progression
  - final typography resolves into the same solid display treatment
- Removed the previous blur/character-spawn approximation from the default Hero.
- Console now types by changing the actual text prefix, not by leaving invisible characters in layout.
  - the caret physically follows the last typed character
  - no frozen white block at the end of the line
  - fast sequential character typing
  - short pauses between lines
- Hero capture cadence increased for smoother raster motion.
- GIF encoding prefers ffmpeg when available, with deterministic Pillow fallback.
