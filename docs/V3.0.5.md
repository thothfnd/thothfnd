# THOTH /FND — V3.0.5 Apple Exact Motion + Hero Layout Fix

## Scope

This patch changes only the Hero animation/capture pipeline.

## Main headline

The selected 21st.dev Apple Hello reference uses two SVG paths animated with
`pathLength: 0 -> 1`, rounded stroke caps and Motion `easeInOut`.

The demo shown on 21st.dev uses `speed={1.1}`.

V3.0.5 mirrors that timing model for the two THOTH headline lines:

- line 1 (`systems`): duration = 0.8 × 1.1, delay = 0
- line 2 (`built different.`): duration = 2.8 × 1.1, delay = 0.7 × 1.1
- easing = cubic-bezier(0.42, 0, 0.58, 1)

The text keeps the current THOTH typography and scale. Its glyph geometry is
custom, but the animation mechanism and cadence match the selected reference.

## Layout

The Hero is now vertically structured:

1. THOTH mark / handle
2. animated headline
3. console directly below the headline

The console is no longer in a competing right-hand column, so the headline
cannot intrude into it.

## Console

- real prefix typing
- 30 visible characters/second
- one visible character per capture frame at 30 fps
- short pauses between lines
- thin caret follows the current character
- caret disappears when the line completes
- no permanent white square/block
