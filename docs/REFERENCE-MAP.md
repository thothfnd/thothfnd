# Visual reference map

These references define behavior, not assets to copy blindly.

- **Apple Hello Effect** — Hero text reveal/motion.
- **Text Marquee** — thin global stats rhythm.
- **Parallax Scroll Feature Section** — editorial project composition and narrative balance.
- **Card Stack / Stacked Panels** — depth and autonomous fan-out using real project media only.
- **Floating Action Button** — compact CTA reveal language; actual README redirects remain real links.
- **8bit-advanced2** — information density/framing for Activity, translated away from literal pixel-art.
- **Agent Plan** — connected progression logic for Recent Commits, not a geographic map.

Hard rule: every major visual must be a chosen reference behavior, a real project asset, a real datum, or a functional necessity.
