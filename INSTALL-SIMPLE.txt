V2 — INSTALLATION SIMPLE

1. Upload/overwrite in your profile repo:
   README.md
   profile.json
   requirements.txt
   scripts/
   assets/
   WORKFLOW-PASTE.txt

2. On GitHub, open:
   .github/workflows/refresh-profile.yml
   Click the pencil (Edit).
   Delete everything in it.
   Copy all of WORKFLOW-PASTE.txt into it.
   Commit changes.

3. Actions -> Refresh animated profile -> Run workflow.

4. When green, reload your GitHub profile.

5. Optional: delete WORKFLOW-PASTE.txt and INSTALL-SIMPLE.txt from the repo afterward.

You normally only edit profile.json.
